# User preferences

Use this entry point when a material behavior choice depends on the user's established TypeScript preferences, or when the user asks why a particular decision was made. Routine use needs no historical lookup.

If the user has a private preference store, resolve it through their established preference workflow (for example, `learned-user-preferences`) and read only the relevant part for `coding-in-typescript`. Preserve their wording, scope, examples, and rationale there. The published skill carries reusable guidance. Keep private evidence in its owning store and apply the current user's instructions first.
